# 📚 DSA-CP in C++ (Data Structures & Algorithms)

This repository is a comprehensive collection of **C++ code and notes** for **Data Structures (DSA)** and **Competitive Programming (CP)** practice.  
It organizes hundreds of solved problems across major topics (Sorting, Trees, Graphs, Dynamic Programming, etc.) to reinforce **algorithmic concepts** and **interview preparation**.

The code is written in **modern C++**, with a strong focus on **efficiency**, **clarity**, and **structured learning**.
